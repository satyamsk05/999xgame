# CodeRabbit Review Target

Deep-review the complete repository, not just changed files. Trace end-to-end flows across Flutter client, backend APIs, PostgreSQL, realtime/WebSocket services, admin operations, external integrations, Docker and AWS deployment.

Prioritize real bugs and production/security risks: login/authentication failures, authorization bypass, game-result integrity, race conditions, wallet/balance consistency, duplicate processing, database transactions, realtime desync, Telegram integration, Flutter runtime/network failures, exposed secrets, unsafe configuration, deployment failures, and missing tests.

Group actionable findings by severity and include file/line, impact, root cause, reproduction/failure scenario where possible, and concrete remediation. Avoid cosmetic/style-only findings unless they create a meaningful correctness or maintainability risk.
