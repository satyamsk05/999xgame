# CodeRabbit Review Scope

Please perform a senior-level, production-readiness review of the entire 999xgame repository.

## Review A-Z
- Flutter/Dart architecture, state management, navigation, lifecycle and async handling
- Backend/API architecture, validation, error handling, concurrency and database access
- Authentication, authorization, JWT/session/token handling and admin permissions
- Game logic and server-authoritative result handling for live games
- Race conditions, duplicate requests, replay/idempotency and transaction integrity
- Wallet/balance, deposits, withdrawals and money-related calculations
- WebSocket/realtime behavior, reconnects, stale state and event ordering
- Telegram integration and external integrations
- AWS/EC2/Docker/deployment configuration and production reliability
- Secrets, environment variables, exposed credentials, insecure defaults and security vulnerabilities
- Input validation, injection risks, CORS, rate limiting, abuse controls and sensitive error leakage
- Flutter UI/runtime crashes, null safety, network failure states and offline/reconnect behavior
- Performance, memory leaks, unnecessary rebuilds/queries and scalability bottlenecks
- Tests, CI/CD, linting, build configuration and missing test coverage
- Dead code, duplicated code, incorrect assumptions, TODOs and incomplete implementations
- Dependency versions and known risky/outdated configuration where evident from repository files

## Review standards
Prioritize real bugs and production risks over style preferences. For every finding, explain the impact, affected file/code, why it is a problem, and a concrete fix. Flag critical/high severity issues clearly. Do not assume code works merely because it compiles; trace important request/data flows across client, API, database and realtime layers.

## Deliverable
Provide a structured A-Z report grouped by severity (Critical/High/Medium/Low), including exact file paths and line references where possible, plus recommended remediation steps. Also identify issues that could cause login failures, incorrect game outcomes, balance inconsistencies, admin/security bypasses, realtime desynchronization, or AWS production failures.
